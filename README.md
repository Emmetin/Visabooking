# Visabooking — мониторинг слотов VFS Global (Франция, Москва)

Скрипт для macOS. Каждые 4–7 минут он проверяет, есть ли свободные слоты на подачу документов на французскую визу в визовом центре VFS Global в Москве. Если слот появился:

- приходит сообщение со скриншотом в **Telegram**;
- Mac показывает уведомление и играет звук;
- мониторинг встаёт на паузу, браузер остаётся открытым на странице записи, и вы **сами** завершаете запись: капча, выбор времени, подтверждение.

Скрипт не обходит капчу и защиту сайта и не подтверждает запись за вас. Так меньше шансов, что VFS заблокирует аккаунт.

> Перед записью в VFS нужно заполнить анкету на **france-visas.gouv.fr**. Без неё запись в VFS может не пройти.

---

## Установка (один раз)

Откройте **Терминал** и выполните:

```bash
git clone https://github.com/emmetin/visabooking.git
cd visabooking
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m playwright install chromium   # запасной браузер, если нет Google Chrome
cp .env.example .env
```

Рекомендуется установленный **Google Chrome**: с ним проверки Cloudflare срабатывают реже.

## Telegram-бот (5 минут)

1. Напишите в Telegram боту **@BotFather** команду `/newbot`, придумайте имя. Он пришлёт токен вида `123456:ABC...`.
2. Откройте `.env` (например, `open -e .env`) и впишите токен в `TELEGRAM_BOT_TOKEN=`.
3. Найдите своего нового бота в Telegram и напишите ему `/start`.
4. В терминале выполните:
   ```bash
   python -m vfs_monitor.telegram_setup
   ```
   Скопируйте показанную строку `TELEGRAM_CHAT_ID=...` в `.env`.
5. Проверьте, что уведомления работают:
   ```bash
   python -m vfs_monitor --test-telegram
   ```

## Первый вход в VFS

```bash
python -m vfs_monitor --login
```

Откроется браузер. Войдите в свой аккаунт VFS (email, пароль, капча, код из письма), потом нажмите Enter в терминале. Сессия сохранится в папке `browser_profile/`, и пароль скрипту не нужен.

## Пробная проверка

```bash
python -m vfs_monitor --once
```

Скрипт откроет страницу записи, выберет центр, категорию и подкатегорию и скажет, есть ли слоты.

**Если в списке нет нужного варианта**, бот пришлёт в Telegram все реальные варианты из этого списка. Скопируйте нужный (достаточно уникальной части слова) в `.env`:

```
CENTRE=Москв
CATEGORY=Кратк
SUBCATEGORY=Туриз
```

Если на странице меньше трёх выпадающих списков, оставьте лишнюю строку пустой, например `SUBCATEGORY=`.

## Запуск мониторинга

```bash
source .venv/bin/activate   # если открыли новое окно терминала
python -m vfs_monitor
```

Терминал и окно браузера должны оставаться открытыми. Свернуть их можно. Чтобы Mac не уснул, запускайте так:

```bash
caffeinate -i python -m vfs_monitor
```

Остановить: `Ctrl+C`.

### Что приходит в Telegram

| Сообщение | Что делать |
|---|---|
| 🟢 **ПОЯВИЛСЯ СЛОТ** | Сразу идите к Mac и завершите запись в открытом окне. Слоты разбирают за минуты. |
| ⚠️ Нужно войти / пройти проверку | Сессия истекла или Cloudflare просит капчу. Сделайте это в окне браузера, мониторинг продолжится сам. |
| ⚙️ Нет варианта в списке | Поправьте `.env` по присланному списку и перезапустите. |
| ❓ Не смог распознать ответ | Посмотрите скриншот. Возможно, слот есть или сайт изменился. Пришлите скриншот разработчику. |
| ⛔ VFS ограничил доступ | Скрипт сам ждёт 30 минут. Если повторяется, увеличьте `INTERVAL_*` в `.env`. |

## Важно

- Не ставьте интервал меньше 3–4 минут: VFS банит за частые запросы. Скрипт не даст поставить меньше 2.
- Не запускайте несколько копий одновременно и не заходите в тот же аккаунт с другого устройства, пока работает мониторинг.
- Файл `.env` и папка `browser_profile/` хранятся только у вас и не попадают в git.
- Скриншоты сохраняются в папку `screenshots/`.
